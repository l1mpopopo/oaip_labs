# 💻 Основы алгоритмизации и программирования (ОАиП)

Репозиторий содержит лабораторные работы по курсу ОАиП, выполненные в БГУИР (группа 653501).

* **Язык программирования:** C++ (C)
* **Среда разработки:** Visual Studio Code
* **Компилятор / ОС:** Clang / macOS

---

## 📂 Структура репозитория

* [📂 Лабораторная №1](./LR1/) — Изучение линейных алгоритмов, типов данных и базового ввода-вывода.
* [📂 Лабораторная №2](./LR2/) — Разветвляющиеся и циклические процессы. Содержит 12 практических задач.
* [📂 Лабораторная №3](./LR3/) — Работа с массивами, указателями и реализация алгоритмов обработки данных.

*Каждая папка содержит исходный код решений (`.cpp`), а также вспомогательные блок-схемы алгоритмов (`.png`).*

---

## 🛠️ Сборка и запуск через Терминал

Для компиляции и запуска любой задачи на macOS выполните следующие команды:

1. Перейдите в папку с нужным файлом (например, для первой задачи ЛР3):
   ```bash
   cd LR3/Task_1
   ```

2. Скомпилируйте код с помощью компилятора `g++`:
   ```bash
   g++ firstTask.cpp -o program
   ```

3. Запустите исполняемый файл:
   ```bash
   ./program
   ```
